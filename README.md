# Resume / Candidate Screening System

## Overview

This project uses Natural Language Processing (NLP) and Machine Learning to automatically classify resumes into different job categories. It helps recruiters speed up the screening process by analyzing resume text and predicting the most suitable category.

## Features

- Resume text preprocessing
- Data cleaning
- TF-IDF Vectorization
- Logistic Regression Classification
- Resume Category Prediction
- Model Evaluation
- Data Visualization

## Technologies Used

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Google Colab

## Workflow

1. Load Resume Dataset
2. Data Cleaning
3. Text Preprocessing
4. TF-IDF Vectorization
5. Train-Test Split
6. Logistic Regression Model
7. Resume Classification
8. Model Evaluation
9. Data Visualization

## Results

The model successfully classifies resumes into different categories using NLP techniques. This approach can assist recruiters in automating candidate screening and reducing manual effort.

## Future Improvements

- Skill extraction
